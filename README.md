## Exercice 1 — Passage par référence

**1. Résultat affiché :**
```text
25 - 20
```

**2. Différence entre valeur et référence :**

- Par valeur : on modifie une copie.
- Par référence : on modifie la variable originale.

**3. Fonction modifiée :**
```cpp
void modifier(int &a, int &b) {
    a += 5;
    b += 10;
}
```

**4. Rôle de `&` :**

`&` permet de passer une variable par référence et de modifier sa valeur originale.
